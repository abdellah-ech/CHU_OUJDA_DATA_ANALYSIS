# Analyses SQL — CHU Mohammed VI d'Oujda

## Objectif

Ce dossier regroupe les requêtes SQL préparées pour analyser les demandes de stage du CHU Mohammed VI d'Oujda.

## Fichier disponible

- `01_Analyse_Demandes_CHU.sql` : requêtes de comptage et de répartition des demandes par statut, établissement, service, niveau académique et année.

## Outil utilisé

- MariaDB
- phpMyAdmin

## Utilisation

Les requêtes permettent d'explorer les données et de produire des résultats agrégés utiles à l'analyse.

**Remarque :** les données utilisées dans Power BI ont été exportées au format CSV depuis phpMyAdmin, puis nettoyées avec Power Query.
